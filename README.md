# Sorteador de Condições de Vitória

Página simples em HTML, CSS e JavaScript que sorteia **uma carta aleatoriamente** entre as 10 condições de vitória disponíveis.

## Como usar

1. Abra `index.html` no navegador.
2. Clique em **Sortear carta**.
3. Após uma breve animação de embaralhamento, uma única carta será revelada.
4. Clique em **Sortear novamente** para realizar outro sorteio.

## GitHub Pages

O projeto não usa servidor, framework ou dependências externas. Basta publicar os arquivos na branch principal do repositório e ativar o GitHub Pages apontando para a raiz do projeto.
